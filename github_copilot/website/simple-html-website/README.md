# Simple HTML Website

This project is a simple HTML website that serves as a basic template for web development. It includes an HTML file, a CSS file for styling, and a JavaScript file for interactivity.

## Project Structure

```
simple-html-website
├── index.html       # Main HTML document
├── css
│   └── styles.css   # Styles for the website
├── js
│   └── script.js    # JavaScript code for interactivity
└── README.md        # Documentation for the project
```

## Getting Started

To set up and run the website, follow these steps:

1. **Clone the repository** (if applicable):
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd simple-html-website
   ```

3. **Open the `index.html` file** in your web browser to view the website.

## Files Overview

- **index.html**: This is the entry point of the website. It links to the CSS and JavaScript files.
- **css/styles.css**: Contains all the styles for the website, including layout and design elements.
- **js/script.js**: Includes JavaScript functions for adding interactivity to the website.
